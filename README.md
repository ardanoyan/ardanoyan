# Arda Noyan Karasoglu

Industrial engineer (Bilkent University, 2026). I work on optimization and data problems, and I build the
occasional website. In 2026 I was a guest researcher at the Zuse Institute Berlin, in the Interactive
Optimization and Learning Lab, working on Frank-Wolfe methods and the mixed-integer solver Boscia.jl.

## Projects

| | |
|---|---|
| [certified-lmo](https://github.com/ardanoyan/certified-lmo) | Certified lower bounds for inexact linear minimization oracles in Frank-Wolfe, and a rule for reusing one paid bound across iterations. Julia, 336 guard tests, every claim labelled and every withdrawn claim kept. ZIB, 2026. |
| [robust-tfrt-radiotherapy](https://github.com/ardanoyan/robust-tfrt-radiotherapy) | Robust optimization of temporally feathered radiation therapy: a MIP for the schedule, a dual-based robust counterpart over a polyhedral uncertainty set, a proof that the static model only sees plan counts, and a window-coupled fix. Python and Gurobi. Senior project. |
| [income-prediction](https://github.com/ardanoyan/income-prediction) | Customer income prediction for a digital bank, built on the bank's customer data: OLS, LASSO, random forest, XGBoost and LightGBM in R tidymodels, and two Shiny apps. The confidential data stays out; a synthetic generator keeps the notebook runnable. Senior design project with Hayat Finans. |
| [stock-screener](https://github.com/ardanoyan/stock-screener) | A daily US equity screener with indicators, an options-flow signal, scores with reasons, DuckDB, a local dashboard and a backtest that found no edge and says so. Python. |
| [gesplan](https://github.com/ardanoyan/gesplan) | Rooftop solar design in the browser: satellite basemap, draw the roof, automatic module layout, PVGIS yield. Next.js, MapLibre, Terra Draw. |
